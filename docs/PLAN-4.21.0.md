# 4.21.0 外部交接留档与线下确认

> 口径时间：2026-11-24。版本 4.21.0（上一版 4.20.0 外部协同前置层）。
> 本轮不新增数据库表、不写迁移；留痕复用已有 `audit_logs` 哈希链。
> 只证明“资料包已生成并交给人工”，不冒充税局申报、付款回单或审计意见。

## 一、目标

4.20.0 能生成三份交接包，但“这份包什么时候交给谁”没有留痕。4.21.0 补上三个动作：

1. **留档**：把当前税务核对包、付款草稿包或合并审计包写入交接台账，记录类型、期间、包标识、来源摘要、包状态与备注。
2. **线下确认**：人工把包打印/发送/交给代账、出纳或审计师后，点一次确认，台账状态从“已留档”变为“已线下交接”。
3. **来源摘要核验**：台账展示 `source_hash`，并与当前页面重新生成的同 `packet_id` 包比对，显示“与当前包一致 / 不一致”。

三个动作都只追加审计事件，不改账、不改计划、不改合并结果。

## 二、存储口径

- 复用 `audit_logs`，不新增表；该表已在现有 JSON 备份导出/恢复范围内，留痕可随备份迁移。
- 留档事件 `action=HANDOFF`，确认事件 `action=HANDOFF_ACK`。
- `detail` 存 JSON：`v`、`tenant_id`、`kind`、`period`、`group_id`、`packet_id`、`packet_status`、`source_hash`、`note`。
- `detail` 在审计函数内截断到 500 字符；`note` 前后端均限制 120 字。
- 状态只有 `archived`（已留档）与 `handed_over`（已线下交接）；不出现 `submitted`、`paid`、`audited`。

## 三、接口

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/external/handoffs?limit=20` | `gl:read` | 交接台账，按最近活动倒序；默认 20，最大 100 |
| POST | `/api/external/handoffs` | `gl:write` | 生成并留档一份包；同 `packet_id` 幂等，重复调用返回 `created=false` |
| POST | `/api/external/handoffs/ack` | `gl:write` | 把已留档的包标为线下交接；未留档返回 404 |

请求体：

```json
{"kind": "tax|payment|consolidation", "period": "YYYY-MM", "group_id": "", "note": ""}
{"packet_id": "TAX-202611-xxxxxxxx", "note": ""}
```

- `kind` 非法、期间非法、合并包缺 `group_id` 返回 400。
- 集团不存在或无权查看沿用 4.20.0 的 404。
- 台账响应含 `records`、`total`、`archived_count`、`handed_count`、`boundary`。

## 四、来源摘要

- 4.20.0 只有合并包带 `source_hash`；4.21.0 给税务包与付款包也补上 32 位稳定摘要。
- 摘要覆盖整份包除 `generated_at` 与 `source_hash` 外的全部字段，下载文件里可见。
- 留档时若包已带 `source_hash` 直接使用，否则对包体做稳定 SHA-256 摘要。
- 台账把摘要与当前页面同 `packet_id` 的包比对；页面重新生成后包体变化会显示“不一致”，不会静默覆盖旧留档。

## 五、前端

- 三张包卡片各加“留档”按钮；留档后按钮变为“已留档 / 已线下交接”徽标。
- 页面底部新增“交接台账”：总数、仅留档、已交接、操作备注、类型、期间、包标识、来源摘要、留档时间、状态、操作。
- 台账每行“标记已线下交接”只在 `archived` 状态出现；已交接行显示确认时间与备注。
- 备注输入同时用于留档与确认，最大 120 字。
- 亮暗双主题、1800×931 与手机宽度均按现有卡片/表格规范适配。

## 六、边界

- 留档不是税局受理回执，不是银行付款回单，不是审计机构意见。
- 线下确认只代表本机用户声明“已交给人工”，不校验对方是否收到。
- 不新增外部通道、不上传包到第三方、不代发布。
- 台账不提供删除或篡改入口；审计链只追加，清空审计仍走既有管理员入口。

## 七、验证计划

- 后端定向：首次留档、重复留档幂等、确认交接、未留档确认 404、非法 kind/period 400、列表计数、审计链 `verify` 通过。
- 前端：三卡与台账同屏、摘要一致徽标、已交接状态、留档按钮携带类型/期间/备注调用接口。
- 浏览器：演示 2026-11 留档税务包 → 填备注 → 标记线下交接 → 留档付款包，台账显示 2 条、1 条仅留档、1 条已交接；亮暗主题截图。
