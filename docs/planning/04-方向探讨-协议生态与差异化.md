## 四、竞品对比：大厂 vs 优质社区项目
### 大厂（打得好的共同点：入口+执行闭环+合规）
- **蚂蚁支小宝**：4300万+用户；连接支付宝生态能"帮你办事"（查账单/申购）；市场解读+持仓分析+保险选配。→ 启示：**执行闭环**是护城河
- **蚂小财**：对话式+图文并茂+个性化理财服务。→ 启示：数据卡片内嵌对话（moneyhelper v2 已做对）
- **度 Moneyhelper/百灵2.0**：B端风控/小微商户信贷财税打包。→ moneyhelper 不碰信贷，避战
- **招行小招**等银行系：账户直连+合规投顾。→ moneyhelper 不碰交易执行，避战
### 社区优质项目
- **Actual Budget**：local-first 隐私+极快+免费开源，社区插件生态 → moneyhelper 同基因，可互导
- **Beancount 系**：纯文本+git+AI 对账，开发者最爱 → 垂直深度赢法样本
### moneyhelper 差异化定位（一句话）
> **"大厂不敢做的本地隐私 + 社区做不深的确定性财务内核 + MCP 时代最开放的中国财务 Agent"**
三个支柱：
1. **数字永远可复核**（确定性内核 + provenance 审计）——对大厂黑盒的回答
2. **数据永不出本机**（local-first + 可自托管）——对云 SaaS 的回答
3. **全量 MCP 开放**（账本即 MCP Server，任何 agent 可接）——对封闭生态的回答，也是获客引擎

## 五、扩展路线（横向 × 纵向）
