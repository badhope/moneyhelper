## 2. P1 功能 bug（必修）
1. **llm.py L491 `litellm_chat()`**：`cfg.get("api_key")` 键名错误，配置字典键为 `"key"` → API key 永远为 None，纯 DB 配置下该路径鉴权必失败（同文件 L388 用法正确，仅此处错）
2. **service.py `_try_nl_add()`**：多段记账声称"原子"，实际逐条 insert 无事务包裹，中途失败半入库
3. **main.py `batch_undo`**：参数校验失败返回 HTTP 402（Payment Required），应为 400

## 3. P2 可靠性/安全
4. 限流器：新 IP 首请求不计数；`_rate_buckets` 无容量上限
5. `/api/metrics` 在免鉴权白名单内（Prometheus 泄露面）
6. `mem.remember()` 在 async 节点同步调用 mem0 SDK（内部含 LLM 抽取+向量写入）→ 阻塞整个事件循环
7. `agent_graph._savers/_exec_graphs` 用 `id(loop)` 做缓存键，loop GC 后 id 复用风险
8. `tool_set_setting` 白名单键校验不一致（部分键值任意字符串直接入库）
9. tiktoken 未在 requirements.txt 声明，靠 litellm 传递依赖侥幸可用
10. llm.py `retry_policy` 参数形态无效被静默忽略；docstring 声称的 DeepSeek reasoning_content 解析未实现

## 5. 现有能力清单（代码实测）
- **对话内核**：LangGraph 图编排（supervisor 分类 → record/collect_market/collect_ledger/risk/finalize），事件契约 start/step/agent_step/text/final/done
- **记账**：中文自然语言（cn2an 中文数字、多段、相对日期）、大额 HITL 审批、undo 快照
- **行情**：东财 push2/push2his 报价/K线/趋势/搜索/自选（A股/ETF/港美股）
- **确定性计算**：净值/收益率/健康五维评分/目标进度/应急金/DTI/集中度（纯代码，LLM 不产数字）
- **导入**：支付宝/微信账单解析 + 通用 CSV
- **家庭**：多成员、成员借贷、权限
- **Agent 能力**：function calling 工具循环、技能包（supervisor/bookkeeping/portfolio + 自定义技能开关）、AI 生成技能建议
- **生态接入**：MCP Server（FastMCP，Claude Code/Cursor 可直连）+ MCP Client
- **记忆/观测**：mem0 长期记忆（chroma 本地向量，降级 BM25）、Phoenix OTel
- **运维**：JWT 多用户、加密备份（Fernet）、审计溯源、限流、CI（GitHub Actions）、Docker、PWA 前端（React19+Vite+Tailwind+shadcn）

## 7. 对标差距（coding harness 视角，若转型参考）
- Codex Harness（2026-08 开源）：会话状态机/上下文压缩/沙箱执行/审批流/工具路由 —— moneyhelper 已有 HITL 审批与工具路由同构物，缺沙箱与压缩
