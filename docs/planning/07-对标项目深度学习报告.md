## A. 大厂系（入口+执行闭环+合规是共同护城河）

### 1. 支小宝 2.0 / 支小助（蚂蚁）
- **定位**：C 端 AI 生活/理财管家（百灵大模型），B 端"支小助"服务理财/保险/投顾
- **规模**：1.0 检索式已服务 3 亿用户/17 亿次问答；2.0 生成式 2024-04 测试即 1200万+；日均调用 559 万次
- **学什么**：①"数百个金融接口工具"作服务中枢——工具广度即能力上限；②从"检索式→生成式"的平滑演进路径（moneyhelper 确定性内核→LLM 叙述是同构思路）；③B/C 双端分线，B 端变现养 C 端
- **弱点可打**：数据在蚂蚁云端，隐私焦虑真实存在；无记账（只有理财）
- 【moneyhelper 动作】坚守"记账+可复核"，做它不敢做的本地化；B 端思路可借鉴（给家庭/小商家管账的 Pro 版）

### 2. 钱迹（600 万用户，个人团队做成）
- **定位**："三无"（无广告/无开屏/无理财），极简纯记账
- **学什么**：①克制品类定位=信任=口碑（跟 moneyhelper "LLM 不碰数字"同一哲学）；②全平台覆盖（Android/iOS/鸿蒙/Mac/Win）；③工作日志公开（运营透明化拉近距离）；④数据免费云同步解决丢数据痛点
- 【moneyhelper 动作】"三无"式克制文案学过来：moneyhelper 可提"无追踪/无云上传/无诱导消费"；开发日志公开是零成本获客

### 3. 木木记账（AI 自动记账新秀）
- **定位**："不是记账 App，是可自由搭建的个人进销存系统"——钱/物/资产/订阅/关系自由组合
- **学什么**：①把"记账"升维成"个人资产系统"的叙事；②自由搭建的模块化数据模型；③AI 自动记账=付完款弹卡片、金额商户预填好、看一眼确认——把录入成本压到 1 秒
- 【moneyhelper 动作】NL 记账已是同类，但"支付后弹卡片预填"的交互值得做 PWA 通知/分享导入；"自由搭建"思想用于技能包

### 4. 一木记账 / 飞鸭（AI 自动记账成熟度对标）
- **学什么**：①微信/支付宝支付后自动弹卡片最成熟（2026-06 评测公认）；②OCR/通知监听多通道录入；③家庭成员共享账本交互
- 【moneyhelper 动作】moneyhelper 已有支付宝/微信 CSV 导入，下一步补"实时卡片"通道（安卓通知监听/分享面板），录入摩擦再降一档

## B. 消费级 AI 记账（海外，订阅制样本）

### 5. Monarch Money（Mint 关停后的最大赢家）
- **定位**：long-view 仪表盘（净资产长期曲线为中心），全账户聚合
- **学什么**：①Mint 之死（2024-03 关停）创造真空——**替代时机学**：巨头撤出=开源/新秀窗口，支小宝们不敢做的隐私位同理；②以净资产为主视觉的仪表盘（moneyhelper Dashboard 是卡片堆，可加净资产长周期主视图）；③月度 AI 复盘（"让 AI 审阅这个月"被用户列为最佳功能）——moneyhelper 晨报可升格为"月度 AI 审计报告"；④多人协作账本定价（家庭计划溢价）
- 【moneyhelper 动作】Dashboard 加净资产长周期曲线；晨报+月度复盘双节奏

### 6. Copilot Money（设计驱动）
- **学什么**：①"beautifully designed"作为第一卖点——设计即获客；②洞察卡片（insight cards）交互；③订阅制但只做 Apple 生态换来极致打磨
- 【moneyhelper 动作】shadcn 底子好，把数据卡片打磨到"截图可传播"水平（开源项目靠截图传播）

### 7. Fina Money（AI-native 最激进）
- **定位**："the most flexible finance tracker"——AI + 自由搭建板块（blocks）组合出任意视图
- **学什么**：①flexible blocks：用户用积木拼仪表盘，AI 补全计算——极致自定义与用户共识 1（高度自定义）完全同频；②AI chat 与仪表盘联动（问句直接生成板块）；③变更日志公开透明（Fina Docs changelog）
- 【moneyhelper 动作】06 文档"自由搭建"落点：Agent 面板+数据卡可配置化，问句生成视图

### 8. ChatGPT 个人财务功能（2026-05-15 OpenAI 上线，Pro 用户）⚠️ 最大变量
- **学什么**：巨头把"财务洞察"做成通用助手的功能而非独立 App——**独立垂直 App 必须回答"为什么不用 ChatGPT"**：答案=账本数据本地、数字可复核、记账闭环、中国账单生态（ChatGPT 不会解析微信支付宝账单）
- 【moneyhelper 动作】README 明确放"对比 ChatGPT 财务功能"页：本地/可复核/支付宝微信原生导入三连击

## C. 开源自托管（moneyhelper 同基因，生态互操作）

### 9. Actual Budget
- **定位**：local-first + 信封预算 + E2E 加密同步（免费），NodeJS
- **学什么**：①local-first 架构标杆（CRDT 增量同步、端到端加密）；②信封预算法交互；③插件/API 生态；④社区治理（GitHub 20k+ star 全靠口碑）
- 【moneyhelper 动作】备份升级为端到端加密增量同步；与 Actual 做互导入（借它的用户池）

### 10. Firefly III
- **定位**：自托管复式记账王者，规则引擎+自动导入调度
- **学什么**：①复式记账严谨性（moneyhelper 单式+持仓混合，可保留但提供复式视图）；②Data Importer 独立子项目——导入做成独立组件复用；③无人值守定时自动导入（cron 拉/解析/入账）；④文档站极完善（自托管教学即 SEO 获客）
- 【moneyhelper 动作】导入器独立化+定时自动导入；文档站做自托管教程（SEO）

### 11. Ghostfolio
- **定位**：自托管投资组合追踪（净值/FIRE 计算/隐私 first）
- **学什么**：①投资组合与记账分野清晰（moneyhelper 两头都做是差异化也是负担）；②"隐私优先"作为 Slogan 首位；③Ghostfolio 用"活动时间线+资产分配"讲故事
- 【moneyhelper 动作】持仓模块对齐它的净值/FIRE 视角；口号学它直白

## D. 开发者向/生态型

### 12. OpenBB（开源金融工作台→AI Workspace 转型）
- **学什么**：①转型路径：数据终端→AI Workspace（agent 接入平台）——**moneyhelper 同款演进路**；②OpenBB AI SDK：type-safe 模型让任何 agent 接入 Workspace（2026-08 文档）——moneyhelper 的 MCP Server 就是同物，差 type-safe SDK 包装与文档；③"任何分析变交互仪表盘"——问答结果一键成卡（moneyhelper 数据卡已做，可加"存为仪表盘"）
- 【moneyhelper 动作】MCP Server 加类型安全 SDK 层+接入文档，学它把"接入"做成产品级体验

### 13. Beancount + Fava（纯文本记账生态）
- **学什么**：①纯文本+git=版本化账本（审计/回滚/协作终极形态，moneyhelper undo 是其雏形）；②Fava 新增 AI 助手（向账本问现金流）与智能导入（账单→已审核分录）——老生态也在 AI 化，验证方向；③银行同步生态（fava 面板直接连银行）
- 【moneyhelper 动作】"导出为 beancount"钩子进 06 路线图不变；对账"已审核分录"交互（AI 预填+人审核）抄过来

## E. 跨项目规律总结（12+ 项目提炼 7 条）
1. **录入摩擦决定生死**：赢家都把"记一笔"压到 1-2 秒（弹卡片/NL/自动导入）——moneyhelper NL 记账领先，补实时卡片通道即封顶
2. **信任文案 > 功能列表**：钱迹"三无"/Ghostfolio"隐私 first"/moneyhelper"数字可复核"——克制定位自带传播
3. **巨头撤出/不敢做的缝隙 = 开源窗口**（Mint 之死→Monarch；云端焦虑→local-first）
4. **AI 复盘 > AI 问答**：用户留存靠"月度审阅"（Monarch）而非随时问答——moneyhelper 晨报是雏形，升格月度 AI 审计
5. **文档站=SEO=获客**（Firefly III/OpenBB/Fina 全靠 docs 引流）
6. **接入做成产品**（OpenBB AI SDK）：生态开放不是"有 API"而是"接入体验产品级"
7. **B 端养 C 端**（蚂蚁支小助）：家庭 Pro/小商家管账是 moneyhelper 变现备选

### 15. DeepSeek Harness（dsh · 2026-08-13 开源，5 天 4 万星）
- **定位**：开源 agent harness，哲学=**"没有内核，只有插件"**——模型/工具/技能/会话/沙箱/存储/循环/调度/UI 全部是 Cordis 插件框架上的可替换组件
