# AI Agent 协议/生态全景时间线（2024-11 → 2026-10，按月）

> **归档说明**：本文档记录 2026-10 当时的规划与调研过程，**不代表当前实现**。
> 当前状态以 [PROGRESS.md](../PROGRESS.md) 与代码为准；文中提到的 mem0、自研规则引擎、
> `react_agent`、OpenTelemetry 等已在 2.3.0 移除，多租户在 2.4.0 引入。
> 用途：moneyhelper"外部有的坚决不造轮子，能力拿完不漏"。每月配【moneyhelper 动作】。
> 月份标注"约"者为近似；来源：公开报道 + 官方发布，写档时已交叉核对。

## 2024 年
- **2024-11** Anthropic 发布 **MCP**（Model Context Protocol），开放规范。【动作：✅ 已用 FastMCP；保持 Server+Client 双端】
- **2024-12** MCP 客户端首批接入（Claude Desktop/IDE）；社区开始造 MCP 服务器。【动作：把 tools.py 全量 MCP 化的起点就在这里补课】

## 2025 年
- **2025-01** DeepSeek-R1 开源（推理模型平价化）；Anthropic 发布《Building Effective Agents》最佳实践；**ACP**（IBM/BeeAI）亮相；OpenAI Operator（浏览器操作 agent）。【动作：记账意图分类等低价值调用可换本地/平价推理模型；通读该最佳实践对照 agent_graph.py】
- **2025-02** MCP 服务器生态爆发；LiteLLM/CrewAI 等框架宣布适配。【动作：✅ LiteLLM 已用】
- **2025-03** OpenAI 发布 **Agents SDK** + Responses API，宣布支持 MCP；MCP 规范 **2025-03-26** 版：Streamable HTTP 替代 HTTP+SSE 双通道。【动作：⚠️ moneyhelper MCP 传输层若还是旧 SSE-only，升级 Streamable HTTP】
- **2025-04** Google 发布 **A2A**（Agent2Agent）协议，50+ 企业背书。【动作：暂观望；家庭多成员多 agent 协作是未来备选】
- **2025-05** MCP registry 预告；垂直 MCP 服务器（金融/数据库）大量出现。【动作：调研财务数据类 MCP，行情/汇率可复用外部服务器】
- **2025-06** A2A 捐赠 **Linux Foundation**；MCP 官方注册表 preview 上线；框架三强格局（LangGraph 生产级 / CrewAI 角色快搭 / AutoGen 微软研究系）。【动作：✅ 选了 LangGraph 正确；关注 MCP Registry 上架流程】
- **2025-07** **AG-UI** 协议发布（CopilotKit 主导，agent↔前端事件标准化：流式文本/工具调用/状态同步/生成式 UI）。【动作：⚠️ moneyhelper SSE 事件契约（start/step/text/final）做 AG-UI 映射层】
- **2025-08** Agent 六大趋势（行业报告）：套壳价值重估、长时任务、多 agent 协作。【动作：晨报/定时任务即"长时任务"雏形，可加任务状态查询】
- **2025-09** Anthropic **Claude Agent SDK**（改名发布，含 sub-agent、代码执行、上下文管理）。【动作：学 sub-agent 隔离模式，风控/市场 agent 可独立子代理化】
- **2025-10** **LangGraph 1.0** 稳定；Anthropic **Agent Skills**（技能包=文件夹+说明，渐进披露）发布。【动作：✅ 已用 1.x；⚠️ 自研 checkpoint（_HITL_THREADS）换官方 SQLite/Postgres saver；⚠️ moneyhelper 技能包（instructions.md+tools）与 Agent Skills 规范对齐，可互通】
- **2025-11** MCP 规范 **2025-11-25** 版：**Tasks**（长任务）、**Elicitation**（运行时向用户要输入）增强。【动作：⚠️ 大额记账 HITL 审批迁 Elicitation 标准形态；晨报生成用 Tasks 建模】
- **2025-12** MCP+LangGraph 成为国内教学主流栈；AI Agent 全景对比（规划/并行工具/长思考）。【动作：方向验证——moneyhelper 技术选型与主流完全一致】

## 2026 年
- **2026-01** 四协议格局成型：**MCP**（工具）/ **A2A**（agent 间）/ **ACP**（agent 间轻量替代）/ **ANP**（跨网络发现/身份）。【动作：主攻 MCP，其余协议知悉不追】
- **2026-02** 社区共识四协议互补而非竞争；agent 身份/授权议题升温（财务场景强相关）。【动作：关注 OAuth/OIDC for agents，多用户 JWT 已有底子】
- **2026-03** **AWS Bedrock AgentCore 原生支持 AG-UI**；微软 Agent Framework 1.0 集成 AG-UI；Google ADK 跟进；企业级 agent 落地指南泛滥（MCP=用工具，A2A=协作）。【动作：AG-UI 生态位确认，映射层优先级提高】
- **2026-04** Agent 标准文档类兴起（开放格式：what agents know）；垂直 agent（财务/法律/医疗）赛道报告密集。【动作：竞品扫描（见 04 文档第四节）】
- **2026-05** Agent 标准/互操作继续收敛；学习路线图共识："先跑通再理解最后造轮子"。【动作：与用户共识一致——不造轮子】
- **2026-06** AG-UI"最后一公里"文章确认大厂背书三连。【动作：见 2026-03】
- **2026-08** OpenAI **Codex Harness 开源**（会话状态机/上下文压缩/沙箱执行/审批流/工具路由）；社区盘点 77 个开源项目（Agent 框架/效率/垂直）。【动作：⚠️ 抄三样：上下文压缩策略→context.py、工具沙箱、状态机建模】
- **2026-09** 垂直 agent 深耕期：本地优先+隐私+MCP 开放成为差异化三板斧。【动作：moneyhelper 定位正好压中，见 04 文档】
