# 会话项目卡、只读分享、画布与深度研究

4.16.44 把此前盘点的剩余能力全部放进原有聊天模块：没有新顶层页面，也没有新导航分组。入口只有四个——会话头部「项目资料」「分享」、回答操作条「画布」、输入区「深度研究 / 回答长度」。

## 会话项目卡

入口：会话头部的「项目资料」；空会话的引导区也会显示「给这个会话加项目资料」。

一个会话一张卡，包含三部分：

- **项目指令**：最多 2000 字，每次提问前作为 system 消息注入；
- **固定文件**：最多 10 个，从工作台已有附件里选；每轮自动加入本轮附件 id，不复制、不再上传；
- **项目记忆**：最多 10 条、每条 200 字，只在本会话注入，不写长期记忆。

隔离规则：数据按 `user_id + thread_id` 落库；附件 id 只接受当前用户自己的附件。另一个用户或另一个会话读到的都是空卡。

注入位置：`agent_context.build_turn_context` 把「项目指令 / 项目记忆」放在知识库上下文前后，截断 2600 字，并明确「只作用于当前会话，不得越过安全边界」。实测回答会按项目指令以「项目口径：」开头。

接口：

```text
GET    /api/threads/{thread_id}/context
PUT    /api/threads/{thread_id}/context
DELETE /api/threads/{thread_id}/context
```

## 只读分享

入口：会话头部「分享」。

- 创建时读取该 `thread` 最多 100 条 run，固化 `question / answer / sources / created_at`；不包含 token 用量、模型参数或账本。
- token 由 `secrets.token_urlsafe(24)` 生成；有效期 1–30 天，默认 7 天。
- 公网路径 `/s/{token}` 不带 `/api` 前缀，不要求登录；返回 `Cache-Control: no-store` 与 `X-Robots-Tag: noindex,nofollow`。
- 撤销只把该 token 标记失效；原会话不受影响。撤销或过期后返回 404。
- 分享页所有用户内容先 HTML 转义；只放行粗体、行内代码、列表、标题、代码块；来源链接只允许 `http/https`，并加 `noopener noreferrer nofollow`。

接口：

```text
POST   /api/shares
DELETE /api/shares/{token}
GET    /s/{token}
```

## 回答画布

入口：回答操作条的「画布」。

- 编辑：直接改 Markdown 正文；
- 预览：走现有 `MarkdownPreview` 的 sanitize；
- 下载：导出 `.md`；
- 存入工作台：新增一个 `.md` 附件，原回答不变。

## 深度研究与回答长度

- **深度研究**：开启后强制 `web_search=True`，工具轮次下限提高到 8，系统指令要求拆子问题、至少两种角度核对，并按「结论 / 依据 / 风险与不确定性 / 来源」四节输出；来源只列工具实际返回或正文真实出现的链接。
- **回答长度**：简洁 / 标准 / 详尽三档写进 `session_context`，不改模型、不改路由、不写全局设置；浏览器 localStorage 记住选择。
- 联网搜索 DDGS 兜底加 10 秒超时：网络受限时明确写「联网搜索超时」，不把整轮问答卡死，也不补造来源。

## 边界

- 项目卡是会话级，不跨会话复用；清会话不会自动删 `thread_projects` 行。
- 分享是快照，不随会话继续更新；不含任何账户或模型信息。
- 画布只编辑这一条回答，不反向改写消息。
- 没有做真实温度 / 最大 token 滑杆：参数没有同时穿透工具决策与最终回答两条路径时，宁可不做，也不做「设置不生效」的假功能。
