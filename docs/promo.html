Philosophy

记一笔，问一句
财富管理本该如此

Moneyhelper 把记账、持仓、目标、体检、晨报——这些分散在各个 App 里的财务动作——统一到一个对话界面。 你说"买一杯咖啡 28 元"，它写进流水；你说"帮我看看这个月花多了吗"，它跑一遍体检报告。 数据 100% 留在本地，AI 模型随便换。

Capabilities

一个对话框
顶一柜子理财 App

💰

一句话记账

"早餐 15、地铁 8、发工资 12k"——一句多笔，金额/分类/日期自动解析，支持中文大写数字。

📊

持仓管理

A 股代码直接加减仓，成本均价自动核算，行业集中度风控，贵提示、便宜也给信号。

🎯

财务目标

设目标、每月自动算需存多少，进度条可视化。超额已完成的目标金色高亮。

🔬

5 维体检

月收支、流动性、集中度、目标、订阅——五维度体检 + 短板建议 + 一键行动按钮。

📰

每日晨报

自选行情 + 预算执行 + 临近目标互动——每天早上自动生成，了解今天的财务全貌。

🔒

加密备份

PBKDF2 + Fernet 全量加密备份，口令零存储；恢复时错一字节都拒绝并回滚。

🧠

分层记忆

会话记忆 + 长期记忆 + 经验库。BM25 语义检索，经验反思，主动遗忘。

↩️

全局撤回

SQLite 快照式 undo，Cmd+K 列出最近可撤回操作，点一下恢复。零新依赖。
