## 一、这次改了什么

页面原来能读，但读起来费劲：字号小、重点平、数字之间的关系全靠脑补。4.21.1 没有加新功能，只把已有事实重新排了一遍。

### 1. 顶部总览

- 28px 圆角渐变 Hero，标题 25/30px，副标题 13/13.5px；期间选择器 44px 高。
- “只读导出 / 人工完成最后一步”胶囊放在标题下，边界先于数字出现。
- 右侧 92px 交接进度环：33% / 已交接，配 `1 / 3 份已线下交接`。
- 四格指标：底稿 3、勾稽通过 13/19、已留档 2、已线下交接 1；26px 数字、图标块、进度条与悬浮渐变。

### 2. 税务包

- 税费净额 32–36px；136px 双段环显示费用与利润占收入比例，中心显示 44% 利润率。
- 收入、已过账凭证拆成独立指标块；八项勾稽改成双列检查卡。
- 科目余额改成双列科目卡，负余额红色，借贷发生额保留在副行。

### 3. 付款包

- 流出合计 230,000；新增纯 SVG 现金安全垫图：期初 200,000、流出 230,000、支付后 -30,000，0 基线与 150,000 安全垫虚线同屏。
- 缺口 180,000 用红色提示，负值柱落在基线下方，不再靠一行小字说明。
- 两笔付款指令从表格改成时间线卡，日期、收款方、账户、金额、确定性分层。

### 4. 合并包

- 合并收入、净利润、资产按收入归一化成比例条，量级差异不再误导。
- 主体表改成持股卡：100% / 80% / 20%，`full` / `proportional`，已纳入 / 未纳入，进度条；三张卡在宽屏两列排，避免标签挤在一起。
- 来源摘要改成带链图标的长摘要条。

### 5. 交接台账

- 宽表格改成记录卡：类型、状态、期间、包标识、备注、摘要一致性、留档与线下交接两段路径。
- 桌面 1800px 两列，1300px 一列；卡片内部在宽屏竖排、在半宽卡片下横排，时间线不再被压成 300px。
- 移动端时间线上下两段，日期完整显示；与备注相同的交接备注不再重复渲染。
- 操作按钮 36px，日期与摘要字号上调到 12–12.5px。

## 二、视觉原则

- **不引依赖**：环图用 `conic-gradient`，现金图用原生 SVG，比例条用 div；没有新增 npm 包。
- **只读主题变量**：主色、金色、边框、卡片底全部走现有 token；亮暗双主题都不另起一套色板。
- **图不替代数字**：环图表达结构，精确金额、比例和边界仍以文字为准。
- **移动端先保完整**：390×844 下说明文字最多两行并用 `text-wrap: balance` 均分，日期不截断，台账不横向滚动。
