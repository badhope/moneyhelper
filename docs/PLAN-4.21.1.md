# 4.21.1 外部协同界面可视化重构

> 口径时间：2026-11-24。版本 4.21.1（上一版 4.21.0 交接留档与线下确认）。
> 本轮只改外部协同页的表现层，不动后端接口、数据口径、审计事件与账务结果。

## 一、问题

4.21.0 把能力补齐后，页面仍沿用“密排表格 + 小字号 + 一层层分隔线”的表达：信息能读，但阅读负担重，数字之间的关系要靠用户自己在脑子里拼。用户反馈集中在三点：

1. 字号与组件偏小，视觉重心不明确。
2. 可视化弱，收入、现金、持股这些结构关系没有图形承载。
3. 版式生硬，三张包与台账看起来像同一张表复制了三遍。

4.21.1 把页面改成“总览先给结论，卡片再给明细，台账最后给证据”的阅读顺序。

## 二、范围

- 页面：财务部门 → 账务 → 外部协同。
- 文件：`ExternalPacketPanel.tsx`、新增 `external/ExternalVisuals.tsx`、中英文案。
- 不改：`/api/external/*` 契约、包体字段、`source_hash`、留档/确认状态机、审计链、数据库表。
- 不加依赖：环形图用 CSS `conic-gradient`，现金图用原生 SVG，比例条用 div；不引入图表库。

## 三、视觉结构

### 1. 顶部 Hero

- 28px 圆角渐变底，标题 25/30px，副标题 13/13.5px。
- “只读导出 / 人工完成最后一步”两枚胶囊，先把边界讲清楚。
- 期间选择器 44px 高；右侧 92px 交接进度环，中心显示 `33% / 已交接`，右侧补 `1 / 3 份已线下交接`。

### 2. 四格总览

- 底稿数、勾稽通过、已留档、已线下交接。
- 26px 数字、图标块、细进度条与悬浮渐变；说明文字最多两行，移动端用 `text-wrap: balance` 均分换行。

### 3. 税务包

- 税费净额升到 32–36px；右侧 136px 双段环显示费用/利润占收入比例，中心是利润率。
- 收入、已过账凭证改成独立指标块；八项勾稽改成双列检查卡。
- 科目余额改成双列科目卡，负余额红色显示，借贷发生额留在副行。

### 4. 付款包

- 流出合计 32–36px；新增纯 SVG 现金安全垫图：期初、计划流出、支付后现金三根柱，0 基线与安全垫虚线。
- 支付后现金低于安全垫时显示红色缺口提示，并在图上保留负值柱。
- 付款指令从表格改成按日期排列的时间线卡：序号、收款方、账户、金额、确定性、复核提示分层。

### 5. 合并包

- 合并收入、净利润、资产改成相对收入归一化的比例条，避免三个量级不同的数字并排比大小。
- 主体表改成持股卡：持股百分比、`full/proportional`、已纳入/未纳入与进度条。
- 来源摘要改成带链图标的长摘要条。

### 6. 交接台账

- 从宽表格改成记录卡：类型图标、状态、期间、包标识、备注、摘要一致性、留档/线下交接两段路径。
- 桌面宽屏两列、窄屏一列；卡片内部在宽屏下横排、在半宽卡片下竖排，避免时间线被压扁。
- 移动端时间线改为上下两段，日期不再截断。
- 备注与摘要一致时不再重复渲染同一条交接备注。

## 四、约束

- 所有颜色读取现有主题变量；亮暗双主题必须都通过。
- 数字、状态、边界文案与 4.21.0 完全一致，不做“看起来更完整”的补写。
- 不把环图、柱图当结论；图只表达比例，精确值仍以数字与文字为准。
- 移动端 390×844 下不出现横向滚动、不截断关键日期。
