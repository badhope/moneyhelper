# 对话工作流指南（对话即中枢）

问AI 是 Moneyhelper 的中枢：记账、行情、持仓、晨报、备份、改设置都直接在对话里一句话完成，其余 4 个页签是对话结果的视图。空库首启时首屏直接列出能力清单，照着说即可。

## 1. 一句话记账

| 说法 | 结果 |
|---|---|
| 「咖啡 28 元」 | 记一笔支出（规则秒回，不调模型） |
| 「工资 1w 到账」 | 记收入 10000（支持 万/w/k 缩写、中文数字） |
| 「咖啡 28 元，打车 32 元」 | 一句多笔记账，逐条入账 |
| 「昨天打车 32 元」 | 按昨天日期入账 |

> 规则识别不了时才走模型兜底；回答里带「已记一笔」与撤销指引。疑问句（「我想理财」）不会误记账。

## 2. 行情与自选

| 说法 | 结果 |
|---|---|
| 「看看宁德时代」 | 查实时价/涨跌（`get_quote`） |
| 「宁德时代加入自选」 | 加自选（`add_to_watchlist`），行情页即时可见 |
| 「我的自选怎么样」 | 汇总自选行情 |
| 「分析 600519」 | 拉 K 线 + 市场快照 + 风险分析 |

## 3. 持仓操作

| 说法 | 结果 |
|---|---|
| 「买入 600519 100 股」 | 按现价建仓入持仓（行情不可达时询问成本价补录） |
| 「卖出一半的 600519」 | 半仓卖出（识别「一半/半仓/减半」） |
| 「我的持仓怎么样」 | 持仓市值/盈亏/集中度分析 + 跳转持仓页 |

## 4. 晨报 / 备份 / 体检

| 说法 | 结果 |
|---|---|
| 「生成今天的晨报」 / 「晨报」 | 生成 L1 洞察 / L2 建议晨报并归档 |
| 「备份一下」 | 生成本地加密备份（显示一次性口令） |
| 「做一次全面体检」 | 五维财务体检（应急金/负债/集中度/储蓄率/预算） |

## 5. 记忆与设置

| 说法 | 结果 |
|---|---|
| 「记住我下个月要交房租 5000」 | 存入长期记忆（优先于记账识别） |
| 「默认首页改成持仓」 | 改设置 + 跳转设置页 |
| 「涨跌颜色换成绿涨红跌」 | 切换 `color_scheme=us` |
| 「界面换成英文」 | 切换 `lang=en` |

## 6. 追问承接

上一轮是财务问题后，省略追问自动承接（如「那上个月呢」→ 上个月账本分析，模型只调只读工具，不会擅自落库）。

## 7. 一条完整工作流示例

> 「看看贵州茅台，合适就加自选」 → 「买了 100 股，成本 1500」

模型编排 `search_symbol → get_quote → get_kline → add_to_watchlist`，再按「买入」动作以成本价 1500 建仓 `record_position`——找标的 → 看行情 → 加自选 → 落持仓，全程对话完成；行情页自选、总览与持仓页即时可见，所有数字来自确定性内核或真实行情源，绝不编造。

## 安全边界

- agent 工具循环只暴露**读类 + 自选维护**工具；记账/记忆/买卖/设置/备份/晨报全部由确定性前置分支拦截——模型永远不会擅自改你的数据。
- 每次回答标注来源徽标（规则/确定性/模型）；AI 未配置或调用失败自动降级，服务不中断。
