## 一、企业预算

- 新增 `enterprise_budget_plans`、`enterprise_budget_lines` 两张表，按 `YYYY-MM` 编制收入与费用预算。
- 只允许现存 `income` / `expense` 科目；金额以元输入、分存储；负数、NaN、重复科目拒绝；单计划最多 200 行。
- 实际数只取 `status=posted` 的总账凭证：收入按 `credit-debit`，费用按 `debit-credit`。
- 未预算但有实际发生额的科目单独标 `unbudgeted`；草稿凭证单独计数并给出 warning。
- 前端财务工作区新增「预算资金」页签：期间选择、预算行编辑、执行对比、差异、执行率与状态。

演示数据：主营业务收入预算 420,000 / 实际 410,000；管理费用预算 210,000 / 实际 200,000；财务费用 6603 未预算但实际 30,000。

## 二、资金计划

- 新增 `enterprise_cash_plans`、`enterprise_cash_plan_lines` 两张表。
- 计划日期必须落在目标月份；方向只允许 `in/out`；现金科目只允许 `1001/1002`；确定性只允许 `high/medium/low`；金额必须为正。
- 期初余额由用户填写；实际数只汇总已过账的 1001/1002 现金分录。
- 输出：`as_of`、`projected_end`、实际到日、计划到日、差异、逐日 `series`、安全垫 warning。
- 前端提供期初/安全垫输入、计划行编辑、现金曲线与逐日计划/实际表。

演示数据：期初 200,000、安全垫 150,000；11-05 回款 410,000、11-20 付款 200,000、11-25 税费 30,000；计划期末 380,000。

## 三、P1 能力补全

### 3.1 个人资产调优

- 新增 `calculations/asset_tune.py` 纯函数 `build_asset_tune`。
- 五类确定性候选：应急金缺口、高息负债、单一持仓超限、目标配置漂移、储蓄率低于 20%。
- 每条带 `detail / impact / risk / amount / confidence / requires_confirmation`；不代下单、不代还款、不预测收益。
- 仪表盘在「现在该做什么」后展示，演示账本给出集中度与储蓄率 2 条候选。

### 3.2 财税时序下钻

- 新增 `GET /api/finance/timeline/{month}`，非法月份 400。
- 返回该月已过账凭证、逐行科目、借贷合计与草稿数；无期间返回 `status=missing` 与空列表，不补零。
- 前端月份行可展开凭证与逐行科目，再点收起。

### 3.3 归因规则增强

- `attribution_rules` 新增 `merchant`、`min_amount_cents`、`max_amount_cents`、`member_id`。
- 关键词、商户、金额绝对值区间、成员任一不满足即跳过；候选 `matched` / `reason` 写明命中维度。
- 老库由 `migrate_columns.py` 补列；金额区间上限小于下限返回 400。
- 账户维度未做：`transactions` 只有 `owner_id`，没有账户字段，不造伪字段。
