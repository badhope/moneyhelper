# 财务数字身份证与月度结账复盘

两块都只读本机账本，数字由确定性计算产生，不调用模型算钱。入口都在原有页面内：数字身份证是总览卡片，月度复盘是「账务」分组页签，不新增顶层板块。

## 财务数字身份证

`GET /api/identity/card?lang=zh|en`

- 总览卡片展示指纹、净资产、可动用现金、流水/有数据月份、风险项数量。
- 「查看完整档案」展示财务坐标、数据覆盖、风险与异常、模型权限、数据来源。
- 指纹是规范化数据摘要（`MH-` + SHA-256 前 16 位），用于核对两次结果是否来自同一份数据，不是身份证号。
- 不读取身份证号、银行卡号、密码；账号控制只统计实际已授权连接。
- 模型可读取、整理、起草和生成摘要；不可代登录、代转账、代下实盘单、绕过风控。

## 月度结账复盘

`GET /api/review/monthly/{YYYY-MM}?lang=zh|en`

- 收支四格：收入、支出、结余、储蓄率；结余带上月对比，储蓄率带目标。
- 预算执行：总预算与分类预算；未设置时明确说明，不伪造进度。
- 支出结构、异常支出、订阅、负债、目标进度。
- 数据体检 5 项：本月有流水、收入已记录、支出已记录、没有未分类流水、预算已设置；输出完成度与是否足够复盘。
- 下月动作最多 3 条，按确定性规则生成：无数据、预算未设、现金流赤字、储蓄率低于目标、分类超预算、异常支出、应急金缺口、订阅审计、目标落后；没有硬性异常时才给「保持并把结余转走」。
- 未来月份与非法年月返回 400；复盘不会冻结流水，不是会计锁账。

## Agent 工具

- `get_financial_identity`：无参数，返回身份证聚合。
- `get_monthly_review`：参数 `month`（`YYYY-MM`，可省略为当前月）。
- 两个工具都登记为只读，不需要人工确认；模型只能引用工具返回的数字和动作。
- 同步暴露到 MCP 只读工具面，MCP 客户端与站内模型调用同一套确定性聚合。
