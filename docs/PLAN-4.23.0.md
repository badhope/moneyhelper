# 4.23.0 AI 托管台与电商经营测算

> 口径时间：2026-11-24。版本 4.23.0（上一版 4.22.0 外部投递通道）。
> 主线：内容社区暂缓；先把已有能力做成「手动全流程 / AI 一键接管」双轨，并把税务场景打磨完整，再给电商一个可用的经营测算工具与开放平台入口。
> 原则：能真实执行的就接真实链路；不能真实执行的只留入口与边界，不做假按钮；用户确认规则可预设，系统按规则自动跑。

## 一、问题

4.22.0 已经能把税务、付款、合并资料包真实送出去，但每一步仍要人点：生成包、选通道、确认发送、再关账。用户要的不是「更多按钮」，而是：

1. **能不做就不做**：常见动作可以预设规则，系统在规则内自动完成。
2. **必须保留控制权**：想手动走完整流程时，原有页面与接口一个都不能少。
3. **确认点要可预设**：金额阈值、通道、是否先看计划，都能提前定；规则内不再打断。
4. **边界不能糊**：税局直连、银行划款、法定合并、社区代发布做不了就明说，不能拿界面占位冒充。
5. **基础能力别从零搓**：成熟 MCP / 开放平台该接就接，系统只做编排、鉴权与审计。

这一轮把「需要人点下一步」的财务动作收敛成策略对象，并把电商从一句口号做成可算、可存、可对照的经营测算。

## 二、范围

### 1. AI 托管台

- 新增表 `autopilot_policies`（按用户 + 动作存模式与规则）、`autopilot_decisions`（每次评估/执行/阻断都留一条）。
- 新增模块 `backend/app/autopilot.py`、`backend/app/routes/autopilot.py`、`backend/app/db/schema_autopilot.py`、`backend/app/db/autopilot.py`。
- 动作先接两个已有、可审计的能力：
  - `tax_deliver`：生成当期税务核对包，过滤掉 `filing_channel` 这类「本来就没有外部通道」的阻断项，从就绪通道里选指定或第一个，执行复用 4.22 的 `deliver()`。
  - `month_end_close`：执行 `enterprise_month_end` 工作流，幂等键按租户 + 账期。
- 三档模式：
  - `manual`：只出计划与证据，绝不执行。
  - `assist`：先出计划，用户点一次确认才执行。
  - `auto`：规则内直接执行；超过金额阈值、缺通道、有数据阻断时回落为待确认或阻断。
- `run-all` 固定先月结、后税务交接，避免税包在关账前生成。
- `dry_run`：只评估，不触发任何外部动作，仍记一条决策并标 `dry_run=true`。
- 决策值只有 `manual / awaiting / executed / blocked / failed`，每用户最多保留 300 条。

### 2. 电商经营测算

- 新增纯确定性计算 `backend/app/calculations/ecommerce.py` 与 `ecommerce_scenarios` 表；不依赖模型，不做「AI 估一个数」。
- 输入覆盖 GMV、退款、订单数、平台佣金、支付费率、推广费、货品成本、履约、其他成本、进项税、增值税率、附加税率、所得税率。
- 输出净销售额、退款率、毛利、贡献毛利、净利、净利率、ROS、客单价、单均净利、当前 ROAS、盈亏平衡广告费与 ROAS、告警。
- 增值税按含税净销售额价税分离，应纳增值税 = 销项 - 进项（不小于 0）；附加税按应纳增值税；所得税只对正利润计提。
- 支持保存/删除方案，历史方案与当前测算并列对照；不写账、不改账。

### 3. 开放平台与 MCP 目录

- 连接中心新增「电商经营」分类，收录抖店、淘宝、拼多多、有赞四个入口；明确「授权后只读订单/账单，不代运营、不代下单」。
- 插件市场新增 `Playwright MCP（浏览器授权读取）`：让 Agent 在用户授权下打开商家后台读取订单与账单，不代下单、不改价。
- 这一层的定位是「接线」而不是「造轮子」：能通过成熟 MCP / 开放平台拿到的能力，不再自研一套抓取器。

### 4. 前端

- 新增顶层视图 `autopilot` 与 `ecommerce`：托管台放「每天看」，电商经营放「业务」。
- 托管台：Hero 显示三档模式计数、账期、一键托管与只评估；两张动作卡切模式即保存；税务卡可配通道与金额阈值；结果卡区分 manual/awaiting/executed/blocked/failed，并识别 `duplicate` 幂等去重；最近决策时间线；边界说明与手动入口。
- 电商经营：左表单右结果，参数改动 320ms 防抖自动算；净利大卡、四格指标、成本条形拆解、告警、保存/删除方案、订单直连引导。
- 修复两个交互问题：切换托管模式后旧结果仍显示旧模式，现在切模式清空该动作结果；删除电商方案后「已保存」提示残留，现在保存提示自动消失、删除即清。

## 四、边界

- 托管台只延展已有的投递与月结能力，不新增外部资质动作。
- 税局直连仍需乐企/服务商；银行划款需持牌与授权；法定合并需审计口径；社区代发布需平台授权。没有这些，系统只给入口与说明。
- `duplicate` 代表同一底稿已按幂等键受理，不代表重复申报或重复付款。
- 电商测算只做经营口径，不替代平台账单、法定报表和纳税申报。
- 内容社区暂停，不在本轮新增假入口。
