# 在聊天里引用工作台文件

入口仍在原聊天输入框，不新增页面：输入 `@` 或点输入区的 `@` 按钮，从右侧工作台已有文件里挑一条，作为本轮上下文发给模型。

## 怎么用

- 输入框尾部输入 `@`，弹出「引用工作台文件」；继续输入文件名可过滤，↑↓ 选择、Enter 确认、Esc 取消。
- 点输入区的 `@` 按钮，会在光标尾部补一个 `@` 并打开同一面板。
- 选中后，文件以带「引用」标识的胶囊挂在输入框上方；可点文件名在工作台预览，点 × 只取消本轮引用。
- 可以直接继续输入问题再发送，不需要先上传。

## 与「上传附件」的区别

| 动作 | 行为 |
|---|---|
| 上传附件 | 把新文件写入工作台附件表，再挂到本轮 |
| `@` 引用 | 只取已有附件的 id 与正文，不复制文件、不新增附件记录 |

因此，引用胶囊点 × 只从本轮移除，**不会删除工作台里的原文件**；上传附件的移除仍按原来的删除语义走。

## 发给模型的内容

前端只传附件 id，后端 `POST /api/ask` 读取附件正文（每份最多 2000 字）拼进本轮上下文，并把 `{id, filename, kind}` 写进 run 的 `attachments`。历史回看时仍显示文件名胶囊，点开走工作台预览。

- 本轮最多 20 个附件 id。
- 同一 id 重复传入会去重。
- 图片、扫描 PDF 没有可检索正文时只保留文件引用，不伪造内容。
- 引用文件不会自动加入知识库；需要跨会话检索时，仍在工作台里手动「加入知识库」。

## 验证

- 真实浏览器：`@` 面板列出工作台 2 个文件；选择「投资方向备忘.md」后出现「引用」胶囊；带引用发送后，回答引用了备忘中的 510880 与 3.429 元。
- 移除引用后工作台仍是 2 个文件，确认没有误删原文件。
- 单测覆盖：`@` 触发边界（行首/空白后、邮箱不触发）、文件名过滤、选中后清理半截触发词。
