# moneyhelper 差异化头脑风暴（大胆版）
> 2026-10-21 · 原则：不要"别人做过的"，每条都要能回答"为什么别人没有/不敢/做不了"

## 〇、一句话定位（三选一，越说越狠）
1. 「别人做的是记账 App，我们养的是一支能自主干活的 AI 财务部门」
2. 「全行业都在让 AI 猜数字，只有我们让数字当庭对质」
3. 「财务 Agent 的可复核性标准，由 Moneyhelper 起草」

## 一、产品层：六招大胆的
### 1. 可辩护财务（Defensible Finance）★核心
- 每个 AI 回答附带"证据包"：数字→SQL→原始凭证→计算代码，一键导出**审计底稿 PDF**
- 桌面对质：任何数字可点开溯源到原始账单截图
- **大胆变体「挑战赛」**：公开挑战 Moneyhelper 的数字，发现一个错=积分/勋章（把"可复核"从卖点变成游戏化营销）；每周公示《错误台账》——敢自曝错题的 AI 全行业找不到第二个
### 2. AI 员工招聘与绩效系统 ★独有
- 换模型=换员工：同一套账本考题**面试**候选模型（GPT/DeepSeek/Qwen 各答一遍），出《会计上岗考核报告》，老板择优录用
- 每个 agent 有工牌/KPI/周报，干得差可以"解雇"（降级/换模型），一键回滚+追责报告
- **大胆变体「外包市场」**：第三方开发者 agent 通过 MCP 注册上岗，先考试后接活——Agent 劳务市场（收入=撮合分成）
### 3. 时间旅行账本（Event Sourcing）
- 账本=事件流，git 式：任何时间点 diff、回滚、"这条记录谁改的"
- **反事实沙盒**：fork 账本跑 what-if（换工作/买房/生娃三年现金流模拟），满意再 merge
- 技术上=event sourcing + LangGraph checkpoint，工程可控，叙事碾压
### 4. 财务治理协议（家庭议会）
- 大额支出触发**家庭投票**：太太批/我批/全票——多人 HITL 审批链
- 企业版同构=报销审批流（一个内核两种卖法）
### 5. 年度账本纪录片
- 年终自动生成 3 分钟数据动画视频（可分享）——传播核弹，竞品只有 PDF 账单
### 6. 适老 Voice-first 管账
- 全语音闭环："Moneyhelper，这个月钱花哪了"→部门自查→语音汇报→语音确认入账
- 中老年不需要学任何界面——会打电话就会管账

## 二、标准层：最狠的一招
**发起《财务 Agent 可复核性开放标准》**（provenance spec for finance agents）
- 把 Moneyhelper 的 provenance/审计底稿/挑战机制写成开放规范，学 A2A 捐 Linux Foundation 的打法
- 让竞品来兼容你的标准——**从竞争者变规则制定者**
- 成本低（写规范+做兼容套件），叙事价值极高（HR/投资人/媒体报道点）

## 三、商业层（不卖订阅的卖法）
1. 审计底稿导出=企业合规工具（B 端付费点：AI 外包财务的可信凭证）
2. Agent 劳务市场撮合分成（生态收入）
3. 私有化部署+审计合规包（中小企业财务外包替代）
4. 技能包商店（流量+分成）

## 四、HR/面试话术（怎么讲这个项目）
### 30 秒电梯稿
"我做了一个 AI 财务部门：多智能体自主分工干活、数字全部可溯源对质、五平台 CI/CD 全自动。3.9 万行代码（3.6 万 + 4 百门面）、546 个测试、LangGraph+MCP 全套现代栈。行业都在做'AI 问答'，我做的是'AI 干活且能追责'。"
### 简历量化弹药
- 混合架构：确定性内核 + LLM 编排（AlphaGo 式"AI 只说不算"）——一句话区分 99% 的套壳项目
- 546 测试基线 / 86 前端单测 / tsc 0 错误 / 五平台 CI-CD / 性能基线入 CI
- HITL 审批链、Event Sourcing 账本、模型招聘 eval 基建（这套词=技术深度证明）
### 高频质疑应对
- "跟 ChatGPT 记账有什么区别？" → 数字可对质+中国账单解析+自主闭环，它只答不做
- "多 agent 是不是伪需求？" → 财务天然分工（记账/会计/风控/投资四岗）+ 审批链是财务的原生形态
- "怎么保证不幻觉？" → 我不保证模型不幻觉，我保证幻觉无法入库（确定性内核+证据包）
### 给 HR 的身份叙事
「我不是做了个 App，我是**管理过一支 AI 员工团队并给它们定考核标准的人**」——这个叙事直接映射管理能力/工程判断力/前沿视野

## 五、验证路径（哪些先做最便宜）
1. 挑战赛+错误台账：零开发成本，README+每周 post 即可启动（信任营销立刻跑）
2. 审计底稿导出：provenance 已有数据，只差 PDF 渲染（~3 天）
3. 模型招聘 eval：evaluate.py 有底子，出一套"会计上岗考题"（~1 周）
4. Event Sourcing 账本：动 db 层，放 M1 模块化时一并设计（别单独立项）
5. 家庭议会：HITL 已有，加多人审批链（~1 周）
6. 纪录片/语音闭环：放 M5 可视化阶段
